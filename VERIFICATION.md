# Проверки

Пройдены 10 тестов, включая транзакционные проверки с PostgreSQL 17.
Прошли линтер и форматирование. Docker API проверен скриптом `scripts/demo.py`:
создание записей, объединение и отмена. На 10 синтетических размеченных парах
получены precision 1,00, recall 0,80, F1 0,889. Пропущена пара с одинаковыми
названием и телефоном без адреса: консервативный порог требует больше оснований.
Эти числа не следует переносить на реальные данные.


## Доработка индекса и рецензирования

14 тестов прошли на PostgreSQL: в том числе каталог из 651 записи, пагинация,
приоритет идентификатора, явное усечение и отклонение устаревшего решения.
Синтетический стенд из 2000 записей: найдены 100 из 100 контрольных пар с общим
идентификатором, 5000 сравнений вместо 199900 для тех же опорных записей.
Все 100 наборов соседей усечены до заданных 50; результат не доказывает полноту
на произвольных данных. Локальное время запросов — 0,51 секунды, без гарантии SLA.
